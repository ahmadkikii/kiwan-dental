# عيادة كيوان لطب الأسنان — الموقع

هذه النسخة Static جاهزة للرفع على GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `styles.css` — التصميم المتجاوب.
- `script.js` — القائمة المتنقلة + جلب الحالات من Supabase.
- `assets/` — صور العيادة والخدمات.

## الحالات
قسم «شاهد بعض حالاتنا» أصبح مرتبطاً مباشرة بجدول `cases` في Supabase.
أي حالة جديدة تُحفظ من لوحة الإدارة تظهر تلقائياً في الموقع العام، مع صور قبل/بعد عند توفرها.

Bucket الصور المستخدم: `case-image`.

لا تظهر تواريخ إضافة الحالات.

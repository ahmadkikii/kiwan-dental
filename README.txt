عيادة كيوان - نسخة الموقع بعد إصلاح عرض الحالات

1) ارفع/استبدل ملفات الموقع الموجودة في مستودع GitHub بهذه النسخة.
2) ملف script.js أصبح يجلب الحالات من Cloudflare Worker بدل Supabase مباشرة.
3) يجب تحديث كود Cloudflare Worker أيضاً بالملف الموجود في الحزمة: worker/index.js
4) لا تغيّر أي شيء في Supabase أو جدول الحالات.
5) بعد رفع النسختين، افتح الموقع وأعد تحميله. الحالات التي حفظتها من لوحة الإدارة ستظهر في قسم "شاهد بعض حالاتنا".

# عيادة كيوان لطب الأسنان — الموقع

هذه نسخة Static جاهزة للرفع على أي استضافة Static مجانية، مثل GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `styles.css` — التصميم المتجاوب.
- `script.js` — الحالات والقائمة المتنقلة.
- `assets/` — صور العيادة ورسومات الخدمات.

## إضافة حالة جديدة
افتح `script.js` وستجد المصفوفة `cases`.
انسخ حالة موجودة، وغيّر:
- `title`
- `desc`
- `before`
- `after`

ثم ضع صور الحالة الجديدة داخل مجلد `assets`.

# عيادة كيوان لطب الأسنان — الموقع

هذه نسخة Static جاهزة للرفع على GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `styles.css` — التصميم المتجاوب.
- `script.js` — الحالات والقائمة المتنقلة.
- `assets/` — صور العيادة ورسومات الخدمات والحالات.

## التعديلات في هذه النسخة
- حذف صورة قسم «عن العيادة» التي كانت موجودة سابقاً.
- استبدال صور الحالات الأربع برسومات توضيحية احترافية متناسقة مع هوية الموقع:
  - تجميل الأسنان
  - تقويم الأسنان
  - زرع الأسنان
  - ترميم الأسنان
- تثبيت عرض أرقام الهاتف من اليسار إلى اليمين حتى لا تنعكس داخل واجهة RTL.
